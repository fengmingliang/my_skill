# 第 3–4 步：检索与创造性论证

## 一、检索执行

### 1.1 三个必查方向

| 方向 | 检索词示例（中/英） | 目的 |
|---|---|---|
| 硬件结构 | 车载举升气囊、底盘气囊、内置千斤顶 / vehicle lifting airbag, onboard jack | 找最接近装置 |
| 控制方法 | 悬架联动脱困、车身姿态调整、陷车自救控制 / suspension-assisted recovery, extraction control | 找最接近方法 |
| 作业流程 | 陷车脱困装置、脱困板、轮胎悬空填料 / vehicle recovery board, tire clearance | 找最接近流程 |

### 1.2 不能只查专利

- **量产产品必须纳入**：车展/发布会公开的方案、官方演示、媒体实测、维修手册、备件目录，同样构成现有技术，且往往是"概念已被公开"的真正障碍；
- **背景谱系单列**：工况不同的近似方案（如水下漂浮气囊、碰撞缓冲气囊、外置人工气囊）单独成节，用于划清边界，正文一行带过即可；
- **供应链线索**：气囊涂层织物、阀组等二级供应商供货信息可作辅助证据。

### 1.3 著录项纪律

每件对比文件记录：公开号、名称、优先权日/公开日、申请人、一句话方案、核心权利点、本质机理、公开链接。

查不到的申请人标"待核实"，**不得推断或编造**。

### 1.4 渠道降级

专业库（如智慧芽等）限流或不可用时，可走公开渠道（Google Patents、Justia、国知局公开页、专利全文 PDF）兜底，但必须：

1. 在交底书检索章注明"本次检索走公开渠道，专业库接口受限"；
2. 给出正式提交前的复核清单，按 IPC 分类号在专业库复核。常用：B60S 9/00（车辆举升）、B60G 17/00（悬架调节）、B60G（车辆悬架一般）。

## 二、差异对比

### 2.1 对比表列结构

本案方案 vs D1/D2/D3 vs 非专利现有技术，逐列对比：

解决的问题｜技术路线｜与原车系统关系｜造隙/举升机理｜软地适应性/承载形态｜关键硬件｜控制时序｜安全保护｜适用场景边界｜主要局限

### 2.2 必须承认重叠

对比不是要把差异说得越大越好。先明确写出"本案与 D1 的重叠特征"，再说"差异在哪"，否则独权撰写会撞车而不自知。

### 2.3 创造性检验：逐条拆"两两组合攻击"

审查员最可能的攻击是"对比文件 A + B 结合显而易见"，按四问逐一拆：

| 检验问题 | 判断方法 |
|---|---|
| 有无组合动机 | A 与 B 是互补关系（同一系统内可自然结合）还是互相替代（选一个就够）？替代关系无组合动机 |
| 技术教导方向是否相反 | 若 B 的教导方向与本案动作相反（如 B 教"一充一放造倾斜"，本案是"四角同步缩回"），本领域技术人员无动机朝本案改 |
| 组合后能否得到协同效果 | 机械叠加是否仍得不到本案特定时序/结构及其带来的叠加收益 |
| 高成本路线能否反证 | 竞品靠昂贵硬件实现同类效果，反证本案低成本路线的创造性 |

### 2.4 风险识别清单

- **上位概念被占**：最接近文件已覆盖"某类硬件 + 抬升 + 脱困"这类上位概括时，纯硬件独权新颖性风险高 → 对策：把上位特征下沉到从权，独权补入时序限定/特定结构，并用方法独权兜底；
- **概念已被产品公开**：若"抬轮→放板→驶出"之类流程已被量产车公开，方法权要不能独占该概念 → 对策：绑定特定两阶段时序与锁止机理；
- **同日双轨**：装置结构同日报实用新型（快授权、易维权），方法与系统报发明。

### 2.5 核心创新点编号制

把真正"拼不出来"的点编号，全稿沿用同一套编号：

- C1：方法时序核心（进方法独权）
- C2：装置结构核心（进装置独权）
- C3：安全控制链（从权或第二独权）

后续有益效果、取证设计、权要布局、交底书成稿全部引用 C1/C2/C3，保证全文可追溯、不出现无来源结论。
