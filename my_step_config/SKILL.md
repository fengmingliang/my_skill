# 版型阶梯图（my_step_config）

一页之内讲清同一车系各版型的价格梯度与配置升级关系：能源分列、价格阶梯、箭头串联、差异随箭头标注。

## 产出形态

同一份 JSON 可渲染两种单页格式（16:9）：

- **HTML**（默认，独立离线页面，无外部依赖）：`scripts/render_step_config.py`。
- **PPTX**（原生一页幻灯片）：`scripts/render_step_config_pptx.py`；微软雅黑、`#C00000` 标题左上、黑正文、白底、无装饰图。用户要 PPT 时直接用该渲染器出 `.pptx`，不再走在线 Slides 流程。

## 工作流程

1. **取数**：优先品牌官网配置页，其次汽车之家/易车/懂车帝等权威媒体。逐版型记录：版型名、能源（EVR/PHEV/HEV/EV）、驱动（四驱/两驱）、指导价；再在同一能源内逐列比对相邻版型，只保留真正发生变化的关键配置。
2. **填 JSON**：字段与规则见 `references/data-schema.md`；实例见 `references/example-m7-896.json`。`adds` 挂在**较低版型**上，描述升到上一版型新增或变化的内容；顶配留空 `[]`。
3. **渲染**：
   ```bash
   python3 scripts/render_step_config.py data.json -o step_config.html
   python3 scripts/render_step_config_pptx.py data.json -o step_config.pptx
   ```
4. **校验（必做）**：浏览器打开截图核对——同一能源在同一列；价格下低上高、同价跨列基本齐平；箭头自下而上且间隙可读；差异框在箭头右侧；无溢出、无方框/标注重叠；分组标签在各自列最高框上方、相对方框居中。价格、驱动、动力参数与来源页面二次核对，存疑项标注「未公布」并向用户确认。

## 布局规范（强制）

- 画布 16:9；标题 `#C00000`、微软雅黑、左对齐于页面左上角；正文黑色；纯白底；除必要产品图外不用装饰性图片。
- **X 向**：一种能源一列，从左到右排列。
  - 增程/混动（EVR/REEV/PHEV/HEV）：浅蓝底 `#EAF2FC`，边框 `#9DBFE8`。
  - 纯电（EV）：浅绿底 `#EAF5EC`，边框 `#9CCBA6`。
- **Y 向**：全图统一价格刻度，同列自下而上指导价递增，同价版型跨列水平对齐；相邻版型保留最小间隙，价格步长过小导致间隙不足时上抬上方版型，保证箭头可读。
- **分组标签**：能源徽标 + 中文能源名，置于本列最高版型框上方，相对版型矩形框水平居中（居中基准只取方框宽度，不计右侧差异文本框）；各列标签随自身最高框定位，不必水平对齐。
- **方框**：一个版型一个，信息居中——第一行仅版型名；第二行 `能源码 驱动 基础版指导价`（能源码与驱动黑色加粗，指导价红色加粗），如 `EVR 四驱 ¥279,800`；若同版型另有六座版，第三行灰色显示 `五座→六座 +X万`，无对应版本则不显示该行。圆角倒角收小，保持精致。
- **标题区**：仅保留主标题（深红、左上）；副标题可选，不写价格口径、行座位加价等解释性说明文字。
- **箭头**：同列相邻版型之间单根竖直线，起止点只落在两框间隙内——从**下方框的上沿**连到**上方框的下沿**，箭头在上方框下沿处指向上方；线身不得穿入方框内部。
- **差异标注**：位于箭头右侧，**无底纹、无边框**；每条一个配置项；`●` 实心＝标配/升级包含，`○` 空心＝选装/需付费；内容尽可能简洁，不写两版一致的背景信息，一条尽量一行，最多两行。
- **图例**：左下角仅保留 `● 标配/升级包含　○ 选装`；不另写价格方向说明文字；数据来源链接显示在右下角小字。

## 差异项选取原则

- 只写相邻版型真正不同的项；两版相同的配置不进标注。
- 优先入列：驱动形式与电机功率、电池类型/容量/电压平台、纯电与综合续航、悬架/底盘、智驾版本与感知硬件、座舱（HUD/后排屏/座椅/方向盘）、座椅布局；外观颜色、普通储物格、全系一致的气囊/雷达等不列。
- 升级后包含的配置用 `solid`；仅选装或需购车后单独购买的软件包/充电桩用 `hollow`。
- 口径：续航写 CLTC；加速写 0-100 km/h；价格注明指导价或权益价；单位与官网一致。

## 数据纪律

- 不迎合、不臆测：参数以来源页面为准，页面未公布的写「未公布」，不凭记忆补数字。
- 交付物中保留来源链接；官网调整配置时以最新页面为准，并在结论中注明取数日期。

## 文件说明

- `scripts/render_step_config.py`：JSON → 单页 HTML 渲染器。
- `scripts/render_step_config_pptx.py`：JSON → 单页原生 PPTX 渲染器。
- `references/data-schema.md`：JSON 字段、填写规则与最小示例。
- `references/example-m7-896.json`：问界 M7（896 线）完整示例数据（五座基础价 + 六座加价第三行）。
