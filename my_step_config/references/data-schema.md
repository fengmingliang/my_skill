# 配置阶梯图 JSON 数据结构

渲染器：`scripts/render_step_config.py data.json -o out.html`（PPTX 用 `render_step_config_pptx.py`）。所有金额单位为元；`price` 用于同列排序与方框展示，展示文案可用 `price_text` 覆盖。

## 顶层字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 页面标题（红色，左上） |
| `subtitle` | 否 | 标题下一行灰色说明；一般留空，不要写价格口径、座位加价等解释性文字 |
| `source` | 否 | 数据来源，显示在页面右下角小字 |
| `groups` | 是 | 能源分组数组，一组一列，顺序即 X 从左到右 |

## group（能源列）

| 字段 | 必填 | 说明 |
|---|---|---|
| `energy` | 是 | 能源码：`EVR`（增程）/`PHEV`（插混）/`HEV`（混动）/`EV`（纯电）；决定列配色 |
| `label` | 是 | 列名，如「增程式混动」「纯电」；渲染为本列最高版型框上方的居中标签 |
| `theme` | 否 | 强制 `blue` / `green`；缺省按 energy 自动映射 |
| `trims` | 是 | 该能源下的版型数组，渲染器按 `price` 升序排列（下低上高） |

## trim（版型方框）

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 版型名，显示在方框第一行，如 `Max 四驱版` |
| `drive` | 是 | `四驱` / `两驱`，显示在方框第二行能源码之后 |
| `price` | 是 | 基础版（本场景为五座）指导价（元，数字），用于同列排序与第二行展示 |
| `six_price` | 否 | 六座版指导价（元）；填写后第三行自动显示 `五座→六座 +X万`（差额＝six_price − price）；无六座对应版型则省略本字段 |
| `price_text` | 否 | 方框第二行价格文案，紧跟能源码、驱动之后；缺省自动格式化为 `¥xx,xxx` |
| `adds` | 否 | 本版型升到上一版型之间的差异项数组；顶配留空 `[]` |

## adds item（差异标注，挂在较低版型上）

| 字段 | 必填 | 说明 |
|---|---|---|
| `mark` | 是 | `solid` 实心圆点＝标配/升级包含；`hollow` 空心圆点＝选装/需付费 |
| `text` | 是 | 差异描述，简明；优先写「下 → 上」的变化，如 `单电机后驱 → 双电机四驱` |

## 填写规则

1. 同列 `adds` 只写相邻版型真正不同的配置；两版相同的配置不进标注。
2. 每条文本控制在 40 字内；动力、电池/续航、悬架、智驾版本与硬件、座舱（HUD/屏/座椅/方向盘）优先入列；颜色、普通储物格等不列。
3. 选装件、需单独购买的软件包/充电桩用 `hollow`；标配或上一版新增包含的用 `solid`。
4. 续航口径写 CLTC；加速写 0-100 km/h；价格注明指导价或权益价口径；查不到写「未公布」，禁止编造。
5. 能源与驱动以官网配置表为准：`单电机后驱/后驱` → 两驱；`双电机四驱` → 四驱。

## 最小示例

```json
{
  "title": "车型版型阶梯图",
  "subtitle": "2026 款",
  "source": "数据来源：品牌官网配置页 https://example.com/config",
  "groups": [
    {
      "energy": "EVR",
      "label": "增程式混动",
      "trims": [
        {
          "name": "Pro 四驱版", "drive": "四驱", "price": 199800,
          "adds": [
            {"mark": "solid", "text": "双电机四驱 → 单电机后驱（两驱）"},
            {"mark": "hollow", "text": "高阶智驾软件包（需单独购买）"}
          ]
        },
        {
          "name": "Max 长续航版", "drive": "两驱", "price": 229800, "adds": []
        }
      ]
    },
    {
      "energy": "EV",
      "label": "纯电",
      "trims": [
        {"name": "Max 长续航版", "drive": "两驱", "price": 219800, "adds": []}
      ]
    }
  ]
}
```

完整实例见 `example-m7-896.json`。
