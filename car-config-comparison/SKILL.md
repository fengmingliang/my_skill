# 汽车核心配置对比

以"行=配置项、列=车型/版型"表格输出。默认：按官方指导价从左到右升序；仅对比标配（选装标注"选装"）；与"上一版型"的差异项加粗标红；在对话框内直接呈现表格，用户要求文件时再交付文件。

## 口径
- **上一版型** = 同车系上一档配置版型；仅当输入含"与上一代/和上代比"等关键字时才比上一代。
- **数据来源**：仅限官网配置表（首选）与汽车之家；两源冲突以官网为准；两者皆无则留空"-"，不猜测、不采信野数据。
- **单位统一**：尺寸 mm、功率 kW、扭矩 N·m、容量 kWh、电压 V、续航 km、油箱 L。

## 流程
1. 确认对比对象与口径（默认按上述口径，用户另要求时调整）。
2. 采集：`general_search` 定位配置页 → `web_fetch` 读取；官网/汽车之家需交互时用 `browser-task`。记录来源与采集日期。
3. 核验：按数据来源规则逐项核对，冲突/留空项记入表注。
4. 输出表格 + 表注（数据来源、采集日期、售价口径、留空项）。

## 关键对比项清单
- **定价**：官方指导价
- **尺寸**：车长宽高、轴距、座位数、后备箱容积
- **动力**：动力形式、驱动形式、电机数量与各功率、增程器（排量/功率）、CLTC 纯电/综合续航、油箱容积
- **电池**：容量、电压、电芯（三元锂/磷酸铁锂）、快充、V2L/V2V
- **减振与底盘**：空簧/螺簧、开式/闭式、几腔几阀、可变阻尼、悬架结构、后轮转向、稳定杆、线控
- **智驾**：舱内/舱外激光、DTOF 数量、毫米波/摄像头数量、智驾芯片与算力、高速/城市 NOA
- **座舱**：屏幕数量与尺寸、是否三联屏/吸顶屏、HUD 类型与尺寸、音响品牌/功率/扬声器数
- **座椅**：按摩、通风、加热、腿托、零重力
- **车门与其他**：电动/电吸门、电动踏板、冰箱、天窗/天幕、轮胎轮毂、其他明显感知项（香氛/氛围灯等）
