# 格式规范：配色、字体与可视化

## 一、配色系统（藏青主题）

### 资产色板（HTML5 / CSS / SVG 内部使用）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#1A2B4A` | 标题、主数据系列、强调元素、KPI数值 |
| 主色浅 | `#3d5a80` | 次要数据系列、辅助强调 |
| 辅助1 | `#758092` | 次要文字、说明文字 |
| 辅助2 | `#BABFC9` | 对比数据系列（非重点）、分隔线 |
| 辅助3 | `#DDE0E4` | 背景色块、卡片边框 |
| 风险/异常 | `#c0392b` | 供给空白、风险提示、关键占比折线 |
| 背景 | `#f5f6f8` | 页面背景 |
| 卡片背景 | `#ffffff` | 内容卡片 |

### 原生 XML 映射（飞书文档 table / callout / text-color）

| 资产角色 | 原生 XML 命名色 |
|---|---|
| 主信息 | `blue` / `light-blue` |
| 次要比较 | `gray` / `light-gray` |
| 不确定/待验证 | `gray` 文字 + `light-gray` 背景 |
| 风险/异常 | `red` 文字 + `light-red` 背景 |
| 表头背景 | `light-gray` 或 `medium-gray` |
| callout 背景 | `light-blue` + `blue` 边框 |

**禁止**：原生 XML 中使用十六进制颜色；只在 HTML5 / SVG / 静态图内部使用精确色值。全篇仅使用一套藏青色板，禁止多套混用。

## 二、字体规范

- 全文统一：**微软雅黑**（Microsoft YaHei）
- 文档标题：加粗，藏青色
- 一级标题：加粗，深色
- 正文：常规，深灰（#333）
- 数据/数字：可加粗，主色或风险色
- 来源/注释：11-12px，浅灰（#999）

## 三、可视化元素选型

| 信息任务 | 推荐元素 | 边界 |
|---|---|---|
| 趋势变化 | ECharts 折线图 + 数据标签 | 不超过2条折线 |
| 构成/占比 | 堆叠柱状图或环形图 | 环形图不超过5个扇区 |
| 精确对比 | 表格（数值右对齐） | 不超过8列 |
| 排名 | 横向柱状图 | TOP10以内 |
| 流程/机制 | 文字+箭头或表格 | 不用装饰性示意图 |
| KPI总览 | 指标卡（4个一排） | 数值+单位+副标题 |

### HTML5 block 硬要求

1. 单文件、无外部依赖（ECharts 用 CDN 或内联）
2. `<head>` 必须包含：
   - `<meta name="use-iframe" content="true">`
   - `<meta name="html-box-height-mode" content="auto">`
   - `<meta name="description" content="图表结论摘要">`
3. 根容器 `width:100%; max-width:100%; box-sizing:border-box`
4. 图表必须有：标题、副标题、数据标签、来源注释
5. 高度自适应（`height: auto`），不设固定像素高度
6. 文件大小不超过 500KB

## 四、排版原则

- **结论先行**：每节首句给结论，后文给证据
- **视觉服从语义**：先确定信息任务，再选图表类型
- **表达互补**：图表已完整表达的，正文只写一句结论，不重复
- **连续视觉禁止**：表格和 HTML5 block 之间至少隔一段正文
- **数据密度**：连续纯正文不超过500字，需插入可视化元素
- **来源标注**：每个图表/表格下方标注来源、时间、口径
