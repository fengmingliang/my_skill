# PPT 格式规范

## 设计系统：轻商务清爽风格

### 全局约束

- **背景**：纯白色 `rgb(255,255,255)`，不使用渐变或纹理
- **字体**：全文微软雅黑，不混用其他字体
- **标题色**：深红色 `rgb(192,0,0)`，加粗，左对齐于页面左上角
- **正文色**：黑色 `rgb(40,40,40)`
- **强调关键词**：深红色 `rgb(192,0,0)`，加粗
- **卡片背景**：浅灰 `rgb(248,248,248)`，边框 `rgb(225,225,225)`
- **结论条背景**：浅红 `rgba(192,0,0,0.06)`，边框 `rgb(192,0,0)`
- **装饰图片**：除必要产品图外，不使用装饰性图片

### 页面布局

- 画布：960 × 540 px
- 标题区：topLeftY=28，height=44，fontSize=26，深红色加粗左对齐
- 标题分隔线：startY=78，深红色 width=2
- 副标题/导语：topLeftY=88，fontSize=14，灰色 `rgb(80,80,80)`
- 内容区：topLeftY=105~128 开始，底部留出来源行（topLeftY=510）
- 来源行：fontSize=10，浅灰 `rgb(140,140,140)`

### 每页一观点原则

每页只表达一个核心观点，论证素材平均分布：
- 三栏卡片：等宽均分，间距均匀
- 表格：表头深红底白字，数据行交替白底/浅灰
- 对比布局：左右对称，关键差异用深红标注
- 数据突出：大数字用深红色 fontSize=28~34

### 演讲者备注

每页 `<note>` 中提供 3-5 句可直接照读的讲稿，包含：
- 本页核心结论
- 关键数据解读
- 与上下页的逻辑衔接

### 标准页面类型

| 页面类型 | 布局特征 |
|---|---|
| 封面 | 大标题居中偏左，深红色装饰线，副标题灰色，日期 |
| 核心结论 | 顶部大数字KPI（2-4个），底部结论条 |
| 数据趋势 | 上方标题，中间HTML/表格，底部结论条 |
| 三栏论证 | 三个等宽卡片，每卡：小标题+大数字+说明+底部结论 |
| 对比表格 | 表头深红，差异行浅红高亮，最后一列标红 |
| 人群/分类 | 2×2卡片网格，每卡：占比大数字+标题+说明 |
| 极化方向 | 横向4列卡片，每列：编号+标题+对比数据+要点 |
| 结论行动 | 顶部总判断条，中部P0/Non-goals双栏，底部验证方式 |
