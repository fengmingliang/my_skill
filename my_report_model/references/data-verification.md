# 数据核实与来源管理规范

确保报告中每个关键数据都经过权威平台交叉验证，来源可追溯，矛盾信息经用户确认后使用。

## 二、数据交叉核实流程

### 步骤 1：识别关键数据

在证据底稿中，将以下数据标记为"必须核实"：
- 所有具体数字（市场规模、增长率、销量、份额、价格、用户数等）
- 排名/第一/最大/最快等定性断言
- 政策法规的生效时间、具体条款
- 竞品对比中的参数差异

### 步骤 2：双源交叉验证

对每个关键数据：
1. 在首选平台找到原始数据，记录标题、发布方、日期、链接
2. 在备选平台或第二独立来源找到对应数据
3. 比对数值、口径、时间范围是否一致

**验证结果分类：**

| 结果 | 判定 | 处理方式 |
|---|---|---|
| 两源一致 | ✅ 已核实 | 直接使用，标注双来源 |
| 两源差异 ≤5% | ⚠️ 基本一致 | 取权威度更高的来源，备注差异 |
| 两源差异 >5% | ❌ 矛盾 | 进入"矛盾信息处理"流程 |
| 仅找到一个来源 | ⚠️ 单源 | 标注"单源待验证"，尽量补充；关键结论不依赖单源数据 |
| 未找到来源 | ❌ 无来源 | 删除该主张或降级为"待验证"假设 |

### 步骤 3：记录核实状态

在证据底稿中为每条事实追加核实字段：

```
[F1] 原子事实内容
    状态：已证实 / 推算 / 待验证
    来源1：[平台名]《标题》，发布方，日期，链接
    来源2：[平台名]《标题》，发布方，日期，链接
    核实状态：已核实(双源一致) / 基本一致(差异x%) / 单源 / 矛盾待确认
    支持的结论：...
```

## 三、矛盾与不确定信息处理（用户确认门）

### 必须触发用户确认的情况

遇到以下任一情况，**必须暂停写作**，使用 `interaction.ask` 向用户确认后再继续：

1. **数据矛盾**：两个权威来源对同一指标给出差异 >5% 的数值
2. **口径冲突**：不同来源对同一概念的定义/统计范围/时间范围不一致
3. **关键事实缺失**：核心结论依赖的数据无法找到权威来源
4. **时效性存疑**：最新数据超过 12 个月，或行业发生重大变化后数据未更新
5. **用户提供数据与公开数据冲突**：用户给出的数字与权威平台数据不一致
6. **政策/法规不确定**：涉及尚未正式发布或存在多种解读的政策
7. **竞品敏感信息**：涉及未公开的竞品内部数据、商业机密

### 用户确认的提问规范

- 一次最多问 3 个问题，按优先级排列
- 每个问题说明：矛盾点是什么、两个来源分别是什么、建议采用哪个及理由
- 提供明确选项，不使用开放式提问
- 示例：

```
问题：2025年中国新能源汽车渗透率，乘联会数据为48.2%，中汽协数据为45.1%，差异3.1个百分点。
建议：采用乘联会数据（口径为乘用车批发量，更贴近市场终端），并在脚注说明中汽协口径差异。
选项：A. 采用乘联会数据  B. 采用中汽协数据  C. 两者并列展示  D. 我来提供准确数据
```

### 用户确认后的处理

- 用户选择后，在证据底稿中记录"用户确认：选择X，时间"
- 若用户提供了新数据，将其作为来源之一，并标注"用户提供"
- 确认后的数据方可进入正文和结论

## 四、报告末尾参考来源规范

### 来源章节结构

报告末尾必须包含"参考来源"章节（h1），结构如下：

```
## 参考来源

### 数据核实说明
- 本报告关键数据均经过至少2个独立权威来源交叉验证
- 核实平台：[列出实际使用的平台，如太平洋汽车、易车、乘联会]
- 数据截止日期：YYYY-MM-DD
- 经用户确认的事项：[如有，列出编号和简要说明；无则写"无"]

### 引用来源
[1] 发布方：《标题》，平台名，YYYY-MM-DD，URL
[2] ...
```

### 单条来源格式

```
[n] 作者/机构：《文章/报告标题》，发布平台，发布日期，完整链接
```

- 按正文引用顺序编号（[1][2][3]...）
- 每条必须包含：发布方、标题、平台、日期、可点击链接
- 日期格式统一为 YYYY-MM-DD
- 链接使用完整 URL，不使用短链
- 同一来源被多处引用时只编一次号

### 来源质量分级标注

在引用来源列表中，对每条来源标注权威等级：

| 标记 | 含义 | 示例 |
|---|---|---|
| 🔴 官方 | 政府部门、监管机构、上市公司公告 | 国家统计局、工信部、巨潮资讯 |
| 🟠 行业权威 | 行业协会、头部研究机构、垂直专业平台 | 乘联会、IDC、太平洋汽车 |
| 🟡 媒体/二手 | 权威媒体报道、第三方转载 | 新华社、财新、第一财经 |

标注方式：在来源条目前加标记，或在"数据核实说明"中汇总说明。

## 五、核实工具使用指引

- 优先使用 `general_search` 搜索权威平台数据，关键词中包含平台名（如"太平洋汽车 比亚迪汉 售价 2025"）
- 对搜索结果中的关键页面，使用 `web.fetch` 获取完整内容，确认数据原文和口径
- 汽车行业可优先使用 `car-config-comparison` skill 获取车型参数对比
- 上市公司数据可使用 `doubao-announcement-analysis`、`doubao-earnings-analysis` 等 skill
- 核实过程中发现的有用原始页面，记录到证据底稿中作为来源

## 六、禁止事项

- ❌ 禁止使用无来源的"据统计""据悉""业内人士透露"
- ❌ 禁止把推算值当作已证实事实陈述
- ❌ 禁止只引用一个来源就对关键数据下结论
- ❌ 禁止在用户未确认的情况下使用矛盾数据
- ❌ 禁止伪造来源链接、日期或标题
- ❌ 禁止使用自媒体、论坛帖子、匿名爆料作为关键数据来源
