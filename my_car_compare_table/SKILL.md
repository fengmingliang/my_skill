# 车型对比表（my_car_compare_table）

输出一张精简对比表 + 一段定位人群总结。不迎合、不吹不黑，每台车只标真正的长板。

## 执行流程

1. **先搜数据再列表**：每款车的价格、尺寸、动力、电池、悬架、差速锁、激光雷达规格、座椅配置等关键参数，必须通过 `general_search` 查官方网站（landrover.com.cn、tanksuv.com、byd.com.cn、lixiang.com 等）或权威汽车媒体（汽车之家、易车、太平洋汽车、懂车帝）核实。**禁止凭记忆填数字**。
2. **数据口径标注**：价格写"限时权益价/指导价"并注明；续航写 CLTC；电池容量与电压平台必须成对出现；尺寸单位 mm。
3. **未知项明确写"未公布"或"—"**，不编造。

## 固定表格行顺序

按以下顺序输出，行名固定：

| 行名 | 内容要求 |
|---|---|
| **指导价** | 区间价格，注明限时权益价/指导价 |
| **车长/轴距** | mm，只写这两个数 |
| **车身结构** | **只写"承载式"或"非承载式（带大梁）"**，不展开 |
| **动力** | 发动机+电机组合、综合功率/马力、零百加速 |
| **电池/电压平台** | **只写电池容量 kWh + 电压平台（400V/800V）**，不写充电时间 |
| **纯电续航（CLTC）** | 数字 km |
| **综合续航** | 数字 km，紧跟纯电续航行 |
| **底盘** | 悬架类型（如云辇-P Ultra / 双腔空悬 / 螺旋弹簧） |
| **差速锁** | 写几把锁、机械还是电子，无锁写"无" |
| **越野模式** | 具体模式名称（蠕行/坦克转弯/i-ATS 等），城市 SUV 写"无" |
| **后轮转向** | **单列一行**，写角度（如 ±10°）或"无" |
| **智驾方案** | 方案名称（华为乾崑 ADS / Coffee Pilot / 理想 AD Max 等） |
| **激光雷达/感知** | **若是华为 ADS，必须列前向激光雷达线数、是否有后向 dToF 固态激光雷达、传感器总数**；其他方案写激光雷达数量即可 |
| **内饰材质** | 主要材质（Nappa/麂皮/真铝/木饰板等） |
| **屏幕** | 几块屏、各屏尺寸，写总数 |
| **冷暖箱** | 有无、容积、温区范围 |
| **音响** | **单列一行**，品牌+扬声器数量 |
| **座椅布局** | 几座、什么布局（2+2+3 等） |
| **座椅** | **单列一行**：布局（几座/什么形式）+ 零重力座椅数量/位置 + 材质/通风加热按摩等关键配置 |

## 表格之后必写两段

### 1. 各自的竞争力长板（分点）
每台车 2–3 句话，**只讲真正的差异化长板**，不讲套话（如"颜值高""空间大"这种）。要点出它为什么值这个价、它和别的车真正不一样的地方在哪。

### 2. 产品关键定位与人群总结（小表格）
| 车型 | 一句话定位 | 核心人群 |
|---|---|---|

最后必须加一段**对用户自己在做/在关注的产品的启示**（如果上下文有提到用户自己的车型），指出这个竞品格局里的空档和威胁。

## 风格要求

- 直接在对话框输出 Markdown 表格，**不生成文件、不做 PPT**（除非用户明确要求）。
- 精简，不要每格写小作文；一个格子 10–30 字能说清就别写 50 字。
- 关键差异项用加粗标出（如唯一带大梁、唯一 400V、最大电池等）。
- 不堆砌装饰性图标、表情符号。
- 数据来源在文末用一行小字注明（如"数据来源：各品牌官网、汽车之家 2026 款车型参数表"）。
