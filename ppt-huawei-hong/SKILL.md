## 二、设计系统（强制规范）

### 2.1 配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色（标题/强调） | `#C00000` | 深红，华为红 |
| 正文 | `#000000` | 纯黑 |
| 模块背景 | `#F2F2F2` | 浅灰色矩形块，用于分割正文不同模块 |
| 页面背景 | `#FFFFFF` | 纯白，简洁素净 |
| 辅助线/分隔 | `#D9D9D9` | 浅灰，仅在必要时使用 |

**禁止**：使用渐变背景、大面积色块装饰、花哨配色。除产品/场景图片外，不使用装饰性图片。

### 2.2 字体

- **全局字体**：微软雅黑（`fontFamily="微软雅黑"`），所有文本元素统一使用，不允许混用其他字体。
- **普通标题**：24 号（`fontSize="24"`），颜色 `#C00000`，加粗。
- **长标题自适应**：如果标题文字较多，24 号无法在一行内展示，则按比例缩小字号（22/20/18），确保**标题始终单行展示**，不换行。最小不低于 16 号。
- **正文**：默认 18 号，颜色 `#000000`。内容较多时可缩至 16 号，确保不溢出。
- **关键词强调**：正文中的关键词**加粗**（`bold="true"`），颜色保持黑色。
- **重点观点强调**：需要特别关注的核心观点，使用 `#C00000` 且**加粗**。

### 2.3 标题位置

- 标题**左对齐**，固定位于**页面左上角**。
- 标题区域建议坐标：`topLeftX="60"`，`topLeftY="40"`，宽度根据内容自适应但不超过页面宽度减 120。
- 标题与正文模块之间保留至少 30px 间距。

### 2.4 正文模块布局（浅灰矩形块）

正文采用**浅灰色矩形块**作为背景，分割不同内容模块。规则：

1. 每个独立论点/论据模块用一个 `<shape>` 矩形包裹，填充色 `#F2F2F2`，无边框或 1px `#D9D9D9` 边框。
2. 模块内边距：左右各 24px，上下各 16px。
3. 模块之间间距：20px。
4. 模块排列：优先上下堆叠（纵向），内容并列时可左右分栏（两栏等宽，间距 20px）。
5. 模块内的文字、图标、数据均在矩形范围内，不溢出。
6. 页面整体留白：左右边距各 60px，顶部标题区下方开始排布正文，底部保留 40px 边距。

**示例结构**（单页多模块）：
```
┌─────────────────────────────────────┐
│ 标题（深红，左上）                    │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ 模块1：核心观点/论据（浅灰底）    │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ 模块2：数据/案例支撑（浅灰底）    │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ 模块3：结论/行动项（浅灰底）      │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

### 2.5 图片使用

- **默认少用**：除必要的产品图片、场景示意图、数据图表外，不使用装饰性图片。
- **产品/场景图**：需要展示产品外观、应用场景、界面截图时，适当补充图片说明，图片应清晰、无多余水印。
- **图片处理**：继承 ppt 技能 Step 6 的图片处理流程（下载→去底色→上传拿 file_token）。白底产品图必须抠图去底色。
- **图片位置**：放入浅灰模块内，或独立成模块，不与文字重叠。

## 三、内容结构规范

### 3.1 整体结构：总分总

整份演示文稿必须遵循**总—分—总**结构：

| 阶段 | 页面 | 内容要求 |
|---|---|---|
| **总（开篇）** | 封面 + 目录/核心观点页 | 封面点明主题；目录页或核心观点页给出全篇核心结论和框架 |
| **分（展开）** | 若干内容页 | 每页一个明确观点，论据围绕观点展开，论证充足 |
| **总（收尾）** | 总结页 + 行动/展望页 | 总结全篇核心发现；给出下一步行动建议或未来展望 |

### 3.2 单页结构：一页一观点

- **每页只表达一个明确观点**，观点简明扼要，不超过 20 字。
- **标题即观点**：页面标题基于正文内容总结提炼，不是泛泛的"背景介绍""数据分析"，而是清晰的判断或结论，例如"Q3 营收同比增长 25%，主要由海外市场驱动"。
- **论据围绕观点展开**：页面内的所有模块（数据、案例、图表、文字）都服务于证明该页观点，与观点无关的内容不放。
- **论证充足**：至少包含 2 个以上论据模块（数据支撑 + 案例/分析，或多角度论证），不允许只有一句话的空泛页面。
- **关键词加粗**：正文中的关键名词、数据、结论加粗。
- **重点观点标红加粗**：页面中最需要听众记住的 1-2 个核心结论，使用 `#C00000` 加粗。

### 3.3 页面类型与默认版式

| 页面类型 | 版式要点 |
|---|---|
| 封面页 | 主标题（可放大至 36-40 号，深红）+ 副标题（黑色，18-20 号）+ 日期/汇报人，居中或左对齐，纯白背景，无装饰图 |
| 目录/框架页 | 列出全篇 3-5 个部分，每部分用浅灰模块横向或纵向排列，当前部分可标红 |
| 观点内容页 | 左上深红标题（观点）+ 2-3 个浅灰论据模块（数据/案例/分析）+ 底部可加一行结论（标红加粗） |
| 数据图表页 | 左上标题 + 图表模块（占页面 60% 以上）+ 1-2 个文字解读模块（关键数据标红加粗） |
| 对比/矩阵页 | 左上标题 + 对比表格或象限图（浅灰底）+ 结论模块 |
| 总结页 | 左上标题"核心结论" + 3-4 个浅灰模块列出全篇关键发现，每条结论标红加粗 |
| 行动/展望页 | 左上标题 + 行动项列表（浅灰模块，每条含动作+责任人+时间）或未来展望 |

## 四、XML 编写要点

在 ppt 技能 Step 7 落 XML 时，注意以下本风格专属要点：

1. **字体声明**：每个 `<text>` 元素都设置 `fontFamily="微软雅黑"`。
2. **深红标题**：标题文本 `color="#C00000"` `bold="true"` `fontSize="24"`（长标题酌情缩小），`align="left"`，位置 `topLeftX="60" topLeftY="40"`。
3. **浅灰模块**：用 `<shape type="rect">` 实现，`fillColor="#F2F2F2"`，`borderColor="#D9D9D9"` `borderWidth="1"`（或无边框），模块内文字用独立 `<text>` 元素叠加在 shape 之上。
4. **关键词加粗**：`<text bold="true" color="#000000">`。
5. **重点标红加粗**：`<text bold="true" color="#C00000">`。
6. **正文默认**：`<text fontFamily="微软雅黑" fontSize="18" color="#000000">`。
7. **模块内边距**：文字的 `topLeftX` 比模块 shape 的 `topLeftX` 大 24，`topLeftY` 大 16；文字宽度比模块宽度小 48。
8. **禁止 emoji**：与 ppt 技能一致，全篇不使用 emoji，语义图标用 IconPark。
9. **图表配色**：数据图表优先使用 ppt 技能的 svg 专业图表（`gen_svg_charts.py`）或原生 `<chart>`，图表配色中主系列使用 `#C00000`，辅助系列使用灰色系。
